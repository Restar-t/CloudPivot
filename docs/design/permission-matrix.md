# 权限矩阵（初稿，M0）

> 对应 PLAN §2.4/§2.5 权限基线。`PermissionResolver.get_role(user_id, space_id)` 是全项目唯一鉴权入口；
> 个人空间 = 单成员空间（OWNER）。M8 做全矩阵回归（T07）。

角色层级：**OWNER > ADMIN > EDITOR > VIEWER**（require_space_role(min_role) 按层级比较）

## 统一纪律

1. **资源不存在 vs 无权限**：对他人的资源 ID 一律返回 `2001 NOT_FOUND`（HTTP 404），不泄露存在性；规则全项目一致。
2. **匿名分享访问**独立于成员体系：校验分享状态/有效期/次数/文件状态/创建者仍有分享权限 + auth_epoch；不要求访问者是空间成员。
3. **VIEWER 下限保护**：预览/下载对 VIEWER 必须放行（不能为收紧而误拒）；移动/复制/分享对 VIEWER 必须拒绝。
4. **所有文件字节流走应用网关**：MinIO 私有桶，浏览器永不直连，无预签名 URL 外发。
